# D&D Adventuring Day XP Calculator

A clean, light-themed, free D&D 2024 (5.5e) adventuring-day XP planner.

## Features
- Level slider from 1 to 20, with a label shown only at the selected value.
- Short-rest slider from 1 to 10, with the selected XP modifier shown beneath the thumb.
- Character count, easy/medium/hard day settings, and live XP totals.
- Add, rename, edit, and remove encounters.
- Copy the encounter plan and save settings automatically in the same browser.
- Mobile-friendly layout and no external dependencies.

## Short-rest modifiers
1 rest: ×0.90; 2 rests: ×1.00; 3 rests: ×1.10; 4–10 rests: ×1.15. The modifier is intentionally capped because additional short rests do not reliably restore more resources indefinitely.

## Publish with GitHub Pages
Upload `index.html` into the root of your repository. In **Settings → Pages**, select **Deploy from a branch**, then `main` and `/ (root)`.

## Disclaimer
Unofficial homebrew tool. The daily budgets are estimates, not official D&D 2024 adventuring-day rules or guaranteed safe encounter thresholds. XP estimates are for encounter building, not necessarily character XP awards.
